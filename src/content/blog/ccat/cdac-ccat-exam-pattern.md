## CDAC C-CAT Exam Pattern

The **CDAC Computerized Common Admission Test (C-CAT)** is a computer-based entrance examination conducted for admission to C-DAC's Post Graduate Diploma and Certificate programmes. According to the official admission booklet, the exam consists of **three independent sections (A, B and C)**, each containing **50 multiple-choice questions** to be completed in **60 minutes**. Candidates attempt one, two or all three sections depending on the course category they are applying for.

---

## Official Exam Structure

| Feature | Details |
|---|---|
| Mode of Exam | Computer-Based Test (CBT) |
| Total Sections | 3 (Section A, B and C) |
| Questions per Section | 50 MCQs |
| Duration per Section | 60 minutes |
| Total Questions | Up to 150 MCQs |
| Maximum Duration | Up to 180 minutes |
| Question Type | Multiple Choice Questions (MCQs) |

Each section is conducted in a separate one-hour slot. Once the allotted time for a section ends, candidates cannot return to it later.

---

## Sections Covered

### Section A

Tests general aptitude and fundamentals.

Topics include:

- English
- Quantitative Aptitude
- Logical Reasoning
- Computer Fundamentals

---

### Section B

Tests programming and core computer science concepts.

Topics include:

- C Programming
- Data Structures & Algorithms
- Object-Oriented Programming (C++)
- Operating Systems
- Data Communication & Computer Networks
- Artificial Intelligence
- Big Data

---

### Section C

Tests electronics and hardware concepts.

Topics include:

- Computer Architecture
- Digital Electronics
- Microprocessors

---

## Marking Scheme

The official marking scheme is:

| Response | Marks |
|---|---:|
| Correct Answer | **+3** |
| Incorrect Answer | **−1** |
| Unattempted Question | **0** |

Since every wrong answer carries negative marking, avoid random guessing. If you can eliminate two or three options confidently, an educated guess may still be worthwhile.

---

## Which Sections Should You Attempt?

The sections you need to appear for depend on the admission category of your chosen course.

| Admission Category | Sections to Attempt |
|---|---|
| Category I | Section A |
| Category II | Sections A + B |
| Category III | Sections A + B + C |

Most software-oriented programmes such as **PG-DAC**, **PG-DBDA**, **PG-AI**, and **PG-ITISS** fall under **Category II**, meaning candidates usually attempt **Sections A and B**.

Programmes related to embedded systems and electronics, such as **PG-DESD**, typically require **Category III**, where all three sections are mandatory.

Always verify the category of your desired course in the latest admission booklet before applying.

## Section B Topic Distribution (Previous Exam Trends)

> **Important:** C-DAC does **not** publish an official chapter-wise weightage. The following distribution is based on trends observed across previous admission cycles and should be treated as an estimate rather than a guaranteed pattern.

| Topic | Approximate Questions |
|---|---:|
| C Programming | 15–18 |
| Operating Systems + Computer Networks | 10–12 |
| Artificial Intelligence + Big Data | 9–12 |
| Data Structures & Algorithms | 9–12 |
| C++ & Object-Oriented Programming | 8–10 |

Actual weightage may vary from one C-CAT examination to another.

## What Kind of Questions Are Asked?

Many aspirants focus only on programming problems, but previous C-CAT papers include a healthy mix of **theory**, **conceptual questions**, and **code-based MCQs**.

### C Programming

Expect questions on:

- Output prediction
- Pointers
- Arrays
- Functions
- Structures
- Memory concepts
- Code snippets

---

### Data Structures

Besides implementation questions, prepare:

- Time Complexity
- Space Complexity
- Searching
- Sorting
- Trees
- Stacks
- Queues
- Linked Lists

Time and Space Complexity are among the most frequently tested DSA concepts.

---

### Operating Systems

Questions often cover:

- Processes
- Threads
- Scheduling
- Deadlocks
- Paging
- Virtual Memory
- File Systems

Many questions are straightforward concept checks rather than lengthy problem-solving exercises.

---

### Computer Networks

Frequently tested topics include:

- OSI Model
- TCP/IP
- HTTP
- DNS
- DHCP
- Routing
- Switching
- TCP vs UDP

Also revise common abbreviations and their full forms, such as:

- MAC — Media Access Control
- DNS — Domain Name System
- DHCP — Dynamic Host Configuration Protocol
- TCP — Transmission Control Protocol
- UDP — User Datagram Protocol

---

### C++ & OOP

Expect direct theory questions on:

- Classes
- Objects
- Constructors
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction
- Virtual Functions

You may also encounter conceptual questions such as:

- Top-down vs Bottom-up programming
- Features of object-oriented programming
- Differences between C and C++

---

## Revision Is Extremely Important

Many C-CAT questions are direct concept-based rather than complex coding problems.

For example, previous papers have included questions on:

- Inventors of C and C++
- OOP principles
- Networking abbreviations
- Operating system fundamentals
- Definitions and terminology

A thorough revision of every subject in the final weeks before the exam can significantly improve your score.

---

## Key Takeaways

- C-CAT consists of **three independent sections** with **50 questions each**.
- Each section has a **60-minute time limit**.
- The marking scheme is **+3 for a correct answer** and **−1 for an incorrect answer**.
- Category II candidates generally attempt **Sections A and B**, while Category III candidates attempt **all three sections**.
- C-DAC does **not** publish official chapter-wise weightage; topic distributions available online are based on previous exam trends.
- Revise theory thoroughly—many questions are direct concept or terminology-based rather than coding-intensive.
