## CDAC C-CAT Best Books

Picking the right books for CDAC C-CAT helps, but buying more books does not always raise your score.

The official C-DAC admission booklet suggests only a few books for each section. If you are starting from scratch, **one good book for each subject and regular MCQ practice is enough.** :contentReference[oaicite:0]{index=0}

This guide lists the best books for each section of the exam.

---

## Section A — English, Aptitude & Reasoning

### English

- **High School English Grammar & Composition** — Wren & Martin

This is still the book most often suggested for grammar and sentence correction. Focus on:

- Articles
- Prepositions
- Tenses
- Error spotting
- Vocabulary

---

### Quantitative Aptitude

#### Beginner

- **Quantitative Aptitude** — R.S. Aggarwal

This book covers nearly every topic asked in C-CAT:

- Percentages
- Profit & Loss
- Time & Work
- Ratio
- Number System
- Probability
- Permutation & Combination

---

#### Additional Practice

- **Quantitative Aptitude** — M. Tyra

This is good for short cuts and speed.

---

### Logical Reasoning

You do not need a separate book for reasoning if you study R.S. Aggarwal well.

For more practice:

- Barron's GRE (Reasoning section)

---

### Computer Fundamentals

- **Foundations of Computing** — Pradeep Sinha & Priti Sinha

Key topics include:

- Number systems
- Boolean algebra
- Basic programming ideas
- Computer organization
- Memory
- Input/Output devices

---

## Section B — Programming & Computer Science

This section often shapes your rank.

---

### C Programming

### 1. The C Programming Language

**Brian Kernighan & Dennis Ritchie**

A classic C book.

Best for:

- Pointers
- Arrays
- Memory
- Functions
- Structures

---

### 2. Let Us C

**Yashavant Kanetkar**

Great for new learners.

Use this first if you are new to C, then move to K&R.

---

### Data Structures

**Data Structures Through C in Depth**

S. K. Srivastava

Focus on:

- Linked Lists
- Trees
- Graphs
- Queues
- Stacks
- Searching
- Sorting

---

### Object-Oriented Programming

**Test Your C++ Skills**

Yashavant Kanetkar

Covers:

- Classes
- Objects
- Constructors
- Inheritance
- Polymorphism
- Virtual Functions

---

### Operating Systems

**Operating System Concepts**

Silberschatz, Galvin & Gagne

Focus on:

- Processes
- Threads
- Scheduling
- Deadlocks
- Memory Management
- Virtual Memory
- File Systems

---

### Computer Networks

**Data Communications and Networking**

Behrouz Forouzan

Read mainly:

- OSI Model
- TCP/IP
- Routing
- Switching
- Ethernet
- DNS
- HTTP
- TCP vs UDP

---

### Big Data & AI

The syllabus only needs basic knowledge.

Good books:

- Fundamentals of Data Engineering — Joe Reis & Matt Housley
- Artificial Intelligence For Dummies — John Paul Mueller

Do not spend too much time here unless you want PG-DBDA or AI-focused courses.

---

## Section C — Electronics

Only needed if you take Section C.

---

### Computer Architecture

**Computer Organization and Architecture**

William Stallings

Key topics:

- CPU
- Memory hierarchy
- Cache
- Pipelines
- Instruction cycles

---

### Digital Electronics

Choose either:

- Digital Design — Morris Mano
- Digital Design: Principles & Practices — John Wakerly

Also useful:

- Modern Digital Electronics — R. P. Jain

---

### Microprocessors

Choose one:

- Microprocessor Architecture, Programming & Applications with 8085 — Ramesh Gaonkar
- The Intel Microprocessors — Barry Brey

Focus on:

- 8085 instructions
- Addressing modes
- Interrupts
- Memory interfacing

---

## Do You Need All These Books?

No.

For most students preparing for **PG-DAC**, **PG-DESD**, or **PG-DBDA**, this set is enough:

- R.S. Aggarwal
- Wren & Martin
- Let Us C
- K&R C Programming
- Data Structures Through C
- Operating System Concepts
- Data Communications & Networking

If you are short on time, spend more time on MCQs and past papers than reading every chapter from start to finish.

---

## Key Takeaways

- Follow the official C-DAC books when you can.
- One book for each subject is enough.
- Focus on C Programming and Data Structures.
- Practice MCQs each day.
- Past papers and mock tests matter more than collecting more books.
